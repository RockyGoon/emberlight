Emberlight is a neon top-down arena survival shooter: you are the last ember, a small wisp of light, holding back waves of shadow wisps. Shoot, collect light shards, and choose an upgrade between waves to survive the dark — including a void wisp boss every five waves.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
